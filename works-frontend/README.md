# bSmart Works Frontend

React + Vite workspace UI for bSmart Works.

## Configuration

Create a local `.env` file when the API is not running at the default local URL:

```bash
VITE_API_BASE_URL=http://localhost:8080/api/v1
```

The app falls back to `http://localhost:8080/api/v1` for local development.

## Scripts

```bash
npm run dev
npm run lint
npm run build
```
